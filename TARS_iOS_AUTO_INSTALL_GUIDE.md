# TARS iOS Companion - One-Click Install Guide

## 🚀 Quick Install (30 seconds)

### Method 1: Shortcut Install (Recommended)
1. **Open this link on your iPhone:**
   ```
   https://php-tamil-mercury-integration.trycloudflare.com/install
   ```

2. **Tap "Quick Install"** - This uses iOS Shortcuts for guided setup

3. **Follow the prompts** - The shortcut will:
   - Open TARS in Safari
   - Guide you through adding to home screen
   - Confirm installation

4. **Done!** Open TARS from your home screen

---

### Method 2: Manual Install (1 minute)

1. **Open Safari** on your iPhone

2. **Go to:**
   ```
   https://php-tamil-mercury-integration.trycloudflare.com
   ```

3. **Tap the Share button** (📤) at the bottom

4. **Scroll down and tap "Add to Home Screen"**

5. **Name it "TARS"** and tap **Add**

6. **Open TARS** from your home screen

7. **Complete the setup wizard** (automatic, ~30 seconds)

## 🆘 Troubleshooting

### "Add to Home Screen" not showing
- Make sure you're using **Safari** (not Chrome/Firefox)
- Try refreshing the page
- Check iOS Settings > Safari > Advanced > Website Data

### Sync not working
- Check internet connection
- Verify TARS backend is running
- Try manual sync button

### Permissions denied
- Go to Settings > TARS > enable Location/Notifications
- Or use Settings within the app
